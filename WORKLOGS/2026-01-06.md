#### Issue #1: Draft 모델 필드명 불일치
**파일**: `backend/routers/drafts.py:774`

**문제**:
```python
# ❌ WRONG
draft = db.query(Draft).filter(Draft.id == draft_id).first()
```

**수정**:
```python
# ✅ CORRECT
draft = db.query(Draft).filter(Draft.draft_id == draft_id).first()
```

**원인**: Draft 모델은 `id` (Integer, primary key)와 `draft_id` (String, business key) 두 개의 ID를 가지고 있음. API 파라미터로 받는 `draft_id`는 String 타입이므로 `Draft.draft_id`를 사용해야 함.
